# Idyllic Lighting - Cursor build pack

This pack contains requirements and agent instructions, not a finished website or approved business assets.

## Start
1. Copy the contents of this folder into the intended project root. Preserve and merge any existing `.cursor` files.
2. Open `docs/BUILD_BRIEF.md` and `docs/SOURCES.md`. The brief is also available as the companion PDF.
3. Review and install the external skills listed in section 13; this archive does not silently install dependencies or third-party code.
4. In Cursor invoke `/idyllic-lighting-build` and paste the prompt in `START_HERE.md`.
5. Build and review the hero prototype before completing the rest of the site.

## Files
- `START_HERE.md`: ready-to-paste kickoff prompt.
- `docs/BUILD_BRIEF.md`: full requirements, creative direction and acceptance criteria.
- `docs/SOURCES.md` / `docs/sources.json`: clickable business and technical references with evidence status.
- `content/business-draft.json`: unapproved content/configuration seed; null fields must stay unpublished.
- `content/asset-manifest.json`: asset provenance and permission register.
- `.cursor/skills/idyllic-lighting-build/`: custom project skill, with self-contained references.
- `.cursor/rules/idyllic-lighting.mdc`: project guardrails.
